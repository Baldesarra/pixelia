Pixelia

Lebendige Pixel-Welten für das ESP32-8048S050C (5"-Display, 800×480)

Installieren per USB

  1. Diese Seite in Chrome oder Edge am Computer öffnen. Firefox und Safari können kein USB.
  2. Das Board mit einem USB-C-Datenkabel anschließen. Reine Ladekabel funktionieren nicht.
  3. Auf „Pixelia installieren“ klicken und den Anschluss „USB-SERIAL CH340“ wählen.
  4. Bei der ersten Installation „Gerät löschen“ bestätigen. Das dauert etwa eine Minute.

Dieser Browser kann nicht per USB installieren. Bitte Chrome oder Edge am Computer verwenden.

USB ist nur über eine sichere Verbindung (https) erlaubt.
