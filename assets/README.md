# assets/ – Grafiken, Paletten und Inhalte

Hier liegen die Quellen für alles, was die Welten zeigen und erzählen:

- **Quell-PNGs** (Sprites, Kacheln, Hintergründe), werden ab 0.5.x von der Asset-Pipeline auf die Paletten umgerechnet
- **Paletten** der Welten (256 Farben, siehe Projektplan 4.2)
- **Datendateien** für Inhalte: Ereignisse, Aktivitäten, Berufe, Gegenstände, Gedanken … (datengetrieben, damit jede
  Patch-Version eine neue „Inhaltswelle“ bringen kann)

Regeln:

- Fremde Grafiken **nur mit CC0- oder CC-BY-Lizenz**. Jede fremde Datei bekommt einen Eintrag in
  [CREDITS.md](CREDITS.md) (Datei, Urheber, Quelle, Lizenz).
- Eigene Grafiken und prozedural erzeugte Inhalte brauchen keinen Eintrag.
- Stil-Leitfaden folgt in `docs/STIL.md` (0.5.x).
